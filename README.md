The Telecom Customer Churn Analysis project is an end-to-end data analytics project 
developed using Python and Power BI. The main objective of this project is to analyze 
customer data, identify patterns related to customer churn, and understand the factors that 
influence customer retention. 
Python was used for data cleaning, preprocessing, and preparation, including handling 
missing values, correcting data inconsistencies, and preparing a structured dataset for the 
analysis. The cleaned dataset was then imported into Microsoft Power BI to develop an 
interactive dashboard with KPIs, visualizations, and filters.
